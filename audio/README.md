# Musica del juego

Coloca los archivos de audio locales con estos nombres:

- `accumula-town-instrumental.mp3`: pista de fondo sin voz, usada por defecto.
- `caminar-vocal.mp3`: version con voz para el boton `CAMINAR`.

La pagina intenta iniciar la musica al entrar. Si el navegador bloquea autoplay con sonido, se activa automaticamente con la primera interaccion del jugador.
